# Risk-Aware Hosting Capacity Analysis for Flexible Load Interconnection in Distribution Networks

The project aims to determine the optimal hosting capacity for integrating flexible loads (e.g., AI data centers, EV stations) into distribution systems without relying on infrastructure upgrades. To maximize capacity, we analyze strategic curtailment over a planning horizon. The method formulates a convex optimization problem with a Conditional Value-at-Risk (CVaR) constraint on curtailment, ensuring bounded expected curtailment during rare grid stress periods. We also employ a weighted l1 penalty to sparsify the curtailment profile, limiting utility-controlled interventions. The project provides a balance between flexible-load hosting capacity, grid reliability, and intervention frequency.
